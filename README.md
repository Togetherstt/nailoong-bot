# Nailoong Bot

基于 `NoneBot2 + OneBot V11 + NapCatQQ` 的自定义 QQ 机器人项目。

当前已实现一个可落地的“奶龙表情包记忆”功能：

- `@123aaa /添加奶龙 奶龙名称`
  前提是这条消息需要“引用一张奶龙图片或 QQ 表情包”
- `@123aaa /随机奶龙`
  机器人会随机发出一张已保存的奶龙表情包，并附带名称、添加者 QQ、添加日期
- `@123aaa /奶龙列表`
  仅管理员 `2484941428` 可用，列出当前奶龙库存
- `@123aaa /删除奶龙 3`
  仅管理员 `2484941428` 可用，按序号删除
- `@123aaa /删除奶龙 憨笑奶龙`
  仅管理员 `2484941428` 可用，按名称精确删除
- `@123aaa /删除奶龙 最近一个`
  仅管理员 `2484941428` 可用，删除最近添加的一条奶龙
- `@123aaa /撤销删除奶龙`
  仅管理员 `2484941428` 可用，恢复上一次删除
- `@123aaa /添加首字母 yzh`
  将 2 到 5 位首字母模式加入姓名库
- `@123aaa /首字母列表`
  查看当前姓名首字母库
- `@123aaa /删除首字母 yzh`
  删除指定首字母模式
- `@123aaa /谐音盒`
  引用一段不超过 40 个中文字符的文本后执行谐音组词匹配
- `引用一段文本 + /盒`
  不需要艾特机器人，直接触发谐音盒快捷入口
  为防止刷屏，命中结果超过 10 条时会随机输出其中 10 条

## 3. 配置机器人到你的小号

下面的步骤按“NapCatQQ 负责挂 QQ，小号接入 NoneBot”这个结构来做。

### 第一步：登录你的小号

1. 打开 `NapCatQQ`。
2. 用你准备用作机器人的小号登录，比如 `123aaa`。
3. 确认这个号能正常收发消息，并且能在目标群或私聊里被正常 `@`。

### 第二步：在 NapCatQQ 中开启 OneBot V11 正向 WebSocket

1. 打开 NapCatQQ 的 OneBot 配置页面。
2. 选择 `OneBot V11`。
3. 连接方式选择 `正向 WebSocket`。
4. 将监听地址配置成：

```text
127.0.0.1:8080
```

5. 如果 NapCatQQ 允许填写 Access Token，请设置一个你自己的 token，例如：

```text
nailoong-local-token
```

### 第三步：在本项目中准备 `.env`

在项目根目录创建 `.env`，至少填入这些内容：

```env
ENVIRONMENT=dev
LOG_LEVEL=DEBUG
HOST=127.0.0.1
PORT=8080
COMMAND_START=["/"]
ONEBOT_ACCESS_TOKEN=nailoong-local-token
SUPERUSERS=[]
VISION_API_URL=https://api.example.com/v1/chat/completions
VISION_API_KEY=sk-xxxxxx
```

说明：

- `HOST` 和 `PORT` 要和 NapCatQQ 的 WebSocket 配置一致。
- `ONEBOT_ACCESS_TOKEN` 要和 NapCatQQ 里设置的 token 一致。
- `COMMAND_START=["/"]` 让 `/添加奶龙`、`/随机奶龙` 这种命令形式更稳定。

### 第四步：启动 Bot

在项目目录执行：

```powershell
D:\Nailoong Bot\.conda\envs\nailoong-bot\python.exe bot.py
```

或者使用热重载：

```powershell
D:\Nailoong Bot\.conda\envs\nailoong-bot\Scripts\nb.exe run --reload
```

如果启动正常，你会在终端看到 NoneBot 初始化和插件加载日志。

### 第五步：确认 NapCatQQ 已连接到 Bot

当 Python 端已经启动后，回到 NapCatQQ：

1. 查看 OneBot 连接状态。
2. 确认它已经连接到 `127.0.0.1:8080`。
3. 如果连不上，先检查：

- Python 端是否还在运行
- `HOST` 和 `PORT` 是否一致
- token 是否一致
- Windows 防火墙是否拦截了本地端口

## 4. 奶龙表情包功能怎么用

### 添加奶龙表情包

使用方式：

1. 先在群里或私聊中发送一张奶龙表情包，或者找到别人发过的奶龙表情包。
2. 引用那条带图消息。
3. 在引用后发送：

```text
@123aaa /添加奶龙 憨笑奶龙
```

名称可以省略：

```text
@123aaa /添加奶龙
```

处理结果：

- 如果引用的是图片，机器人会提取第一张图片并下载到本地 `data/nailoong/images/`
- 如果引用的是 QQ 表情包，机器人会直接保存该表情段的原始消息数据
- 在 `data/nailoong/index.json` 中记录元数据
- 回复当前库存、添加者 QQ、添加日期

### 随机发送奶龙表情包

直接发送：

```text
@123aaa /随机奶龙
```

机器人会返回：

- 一张随机奶龙表情包
- 奶龙名称
- 添加者 QQ
- 添加日期

### 管理奶龙表情包

只有 QQ 号 `2484941428` 可以使用下面两条管理命令。

查看库存：

```text
@123aaa /奶龙列表
```

输出会带序号，格式类似：

```text
1. 憨笑奶龙 | 图片 | 添加者:123456789 | 日期:2026-06-03 02:08:00
2. 未命名奶龙 | QQ表情 | 添加者:987654321 | 日期:2026-06-03 02:15:00
```

按序号删除：

```text
@123aaa /删除奶龙 2
```

按名称删除：

```text
@123aaa /删除奶龙 憨笑奶龙
```

删除最近一个：

```text
@123aaa /删除奶龙 最近一个
```

撤销上一次删除：

```text
@123aaa /撤销删除奶龙
```

说明：

- 按序号删除时，只删除对应那一条。
- 按名称删除时，会删除所有同名记录。
- `/删除奶龙 最近一个` 会删除当前库存中最后添加的一条记录。
- `/撤销删除奶龙` 只恢复最近一次删除动作中的最后一条记录。
- 如果删除的是图片型记录，图片会先移动到本地回收区，便于撤销恢复。
- 如果删除的是 QQ 表情记录，只删除索引记录，撤销时恢复该索引。

## 5. 谐音盒功能怎么用

### 添加姓名首字母

直接发送：

```text
@123aaa /添加首字母 yzh
```

规则：

- 支持 2 到 5 个英文字母
- 会自动转成小写
- 当前不记录添加者和添加时间
- 重启后不会丢失

查看当前首字母库：

```text
@123aaa /首字母列表
```

删除一个首字母模式：

```text
@123aaa /删除首字母 yzh
```

### 使用谐音盒

1. 先准备一条短文本消息。
2. 这条消息的有效中文字符数必须不超过 40。
3. 引用这条消息。
4. 再发送：

```text
@123aaa /谐音盒
```

也支持更方便的快捷入口：

1. 引用一段短文本
2. 直接发送：

```text
/盒
```

这个入口不需要 `@123aaa`。

匹配逻辑：

- 机器人会从引用文本里按原顺序选 3 个候选单元
- 候选单元可以是“单个中文字符”或“连续英文单词”
- 中文字符按拼音首字母计算，英文单词按单词首字母计算
- 如果它和姓名库中的某个首字母模式完全一致，就算命中
- 匹配时选取的候选单元数量，会和首字母模式长度一致；例如 `yz` 取 2 个，`yzhh` 取 4 个
- 如果有多个命中结果，会按匹配顺序输出
- 如果命中结果超过 10 条，会随机抽取 10 条输出，避免每次都完全一样
- 同一条引用文本连续多次触发时，会尽量轮换结果，减少完全重复
- 同一条被引用消息在 5 秒内只会成功盒一次；后续再盒会直接回复“已经盒过了”
- 如果瞬时请求太多，机器人会启用内部缓冲和并发限制；队列满了会直接提示“当前盒子太忙，请稍后再试。”

示例：

如果姓名库里有：

```text
yzh
```

引用文本是：

```text
杨枝花与银之魂
```

则可能输出：

```text
盒出了：
<杨枝花>
<银之魂>
```

如果引用文本混有英文单词，例如：

```text
杨 abc 魂
```

且姓名库中有：

```text
yah
```

则也可能命中：

```text
盒出了：
<杨abc魂>
```

## 6. 数据存储说明

奶龙记忆保存在本地，不依赖数据库。

- 图片目录：`data/nailoong/images/`
- 索引文件：`data/nailoong/index.json`
- 谐音盒首字母库：`data/homophone_box/initials.json`

索引示例：

```json
[
  {
    "id": "5c61d1d1d8db4c4ba0f7c31f5967d876",
    "image_filename": "ea55c5739348423d91242f46d6f85b05.png",
    "added_by": "123456789",
    "added_at": "2026-06-03 02:08:00",
    "original_name": "憨笑奶龙"
  }
]
```

## 8. 已知约束

- `/添加奶龙` 目前只会读取“引用消息”中的第一张可保存资源，优先取第一张图片，其次取第一个可用 QQ 表情段。
- 目前不会自动去重，同一张图重复添加会产生多条记录。
- 目前已支持列表、删除和单步撤销，但还不支持重命名、模糊搜索、分页浏览和多步恢复；后续可以继续加。
- `/谐音盒` 目前要求引用文本中的有效中文字符数不超过 40，但英文单词可以与中文字符混合参与匹配。
- `/谐音盒` 当前按拼音首字母 / 英文首字母精确匹配，不做多音字语境消歧，也不做英文词形归一化。
- `/谐音盒` 与 `/盒` 为防止刷屏，单次最多输出 10 个命中结果；超出时会随机抽取 10 个结果显示。
- `/谐音盒` 与 `/盒` 对同一条引用消息有 5 秒冷却；冷却期内重复触发只回复“已经盒过了”。
- `/谐音盒` 与 `/盒` 在高并发下启用有限缓冲，超过承载时会直接提示稍后再试，而不是无限排队。
